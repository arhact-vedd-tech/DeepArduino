## Глава 9: Датчики (DHT11/DHT22)

### Цель

Подключить цифровой датчик температуры и влажности, прочитать данные через библиотеку, вывести в Serial. Понять, почему DHT «медленный» и что делать с `NaN`.

### Что такое DHT11/DHT22

Цифровой датчик: внутри микроконтроллер, термистор и датчик влажности. Сам измеряет и отдаёт готовые числа по одному проводу данных. Никакой аналоговой математики — только библиотека.

| Параметр | DHT11 | DHT22 |
|---|---|---|
| Температура | 0–50 °C, ±2 °C | −40–80 °C, ±0,5 °C |
| Влажность | 20–80 %, ±5 % | 0–100 %, ±2 % |
| Цена | дешевле | дороже |
| Опрос | не чаще 1 Гц | не чаще 0,5 Гц  |

Для учебных проектов DHT11 достаточно. Если нужна точность или отрицательные температуры — DHT22.

### Установка библиотеки

Нужна **DHT sensor library by Adafruit**. Она тянет зависимость **Adafruit Unified Sensor** — подтверди установку, когда предложит.

В VS Arduino: `Ctrl+Shift+P` → **VS Arduino: Library Manager** → поиск `DHT sensor library` → установить . Не копируй вручную в папку проекта — библиотека должна лежать в глобальной папке Arduino.

### Подключение

| DHT | Uno |
|---|---|
| VCC (+) | 5V |
| DATA (OUT) | Пин 2 (или любой цифровой) |
| GND (−) | GND |

**Подтяжка**: между DATA и 5V резистор **10 кОм**. Многие готовые модули DHT11 уже имеют его на плате — проверь свой. Если модуль голый (три ноги без обвязки) — резистор обязателен, иначе readings будут `NaN` .

### Код: чтение и вывод

```cpp
#include <DHT.h>

#define DHTPIN 2
#define DHTTYPE DHT11   // или DHT22

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
  Serial.println(F("=== DHT start ==="));
}

void loop() {
  delay(2000);  // DHT медленный — не чаще раза в 2 секунды

  float t = dht.readTemperature();  // °C
  float h = dht.readHumidity();     // %

  if (isnan(t) || isnan(h)) {
    Serial.println(F("DHT read failed"));
    return;
  }

  Serial.print(F("T="));
  Serial.print(t, 1);
  Serial.print(F(" C  H="));
  Serial.print(h, 1);
  Serial.println(F(" %"));
}
```

### Разбор

- `DHT dht(DHTPIN, DHTTYPE)` — объект, привязанный к пину и типу. **Тип важен**: если указать `DHT11`, а подключить `DHT22` — значения будут мусорными .
- `dht.begin()` — инициализация в `setup()`.
- `readTemperature()` / `readHumidity()` — возвращают `float`. При сбое — `NaN` (not a number).
- `isnan()` — проверка на сбой. **Всегда проверяй**. DHT иногда срывается, особенно при плохом контакте или частом опросе .
- `delay(2000)` — DHT11 не терпит опрос чаще 1 Гц. DHT22 — чаще 0,5 Гц. Без задержки — `NaN` или мусор.

### Что может пойти не так

- **Всегда `NaN`** — нет подтяжки (10 кОм между DATA и 5V), или датчик не получает питание, или неправильный пин в `#define`.
- **Значения «прыгают»** — опрос слишком частый. Увеличь `delay` до 2000–2500 мс.
- **Температура верная, влажность 0 или наоборот** — брак датчика или плохой контакт. Проверь пайку/макет.
- **`DHT.h: No such file`** — библиотека не установлена или установлена не туда. Library Manager, переустанови.
- **`Adafruit Unified Sensor` не установлен** — компиляция упадёт с ошибкой зависимости. Установи и его.

### Задание

1. Подключи DHT11, загрузи скетч. Открой монитор порта (9600). Убедись, что видишь T и H.
2. Подыши на датчик — влажность должна вырасти, температура слегка измениться. Запиши значения до и после.
3. Убери `delay(2000)`, поставь `delay(100)`. Что произошло с выводом? (Ответ: появятся `DHT read failed` или мусор — датчик не успевает.)
4. Поменяй `DHTTYPE` на `DHT22` (если у тебя DHT11). Что покажет? (Ответ: мусор или `NaN` — протоколы разные.)
