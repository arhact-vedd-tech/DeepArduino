## Глава 4: Цифровой выход

### Цель

Научиться управлять внешними устройствами через цифровые пины: светодиод, ШИМ, реле. Понять, почему резистор — не опция.

### Что значит «цифровой выход»

Пин в режиме `OUTPUT` может быть в двух состояниях:

| Состояние | Напряжение | `digitalWrite` |
|---|---|---|
| HIGH | ~5 В | `HIGH` или `1` |
| LOW | ~0 В | `LOW` или `0` |

Ток через пин — до **40 мА** на пин, **200 мА** суммарно . Это мало. Светодиод — можно напрямую (с резистором). Мотор, реле, серво — **нельзя**, нужен транзистор или драйвер.

### Светодиод: почему нужен резистор

Светодиод — не резистор. У него почти вертикальная вольт-амперная характеристика: после порога открытия (для красного ~1,8 В, для синего ~3 В) ток растёт лавинообразно. Без резистора он сгорит или сожжёт пин.

**Расчёт резистора**:

```
R = (V_пин − V_светодиода) / I_желаемый
```

Для красного светодиода (1,8 В), пина 5 В, тока 15 мА:

```
R = (5 − 1,8) / 0,015 = 213 Ом
```

Ближайший стандартный — **220 Ом**. Для синего/белого (3 В) — **150 Ом**. Для тока 10 мА — 330 Ом (безопаснее для пина).

**Схема**: пин → резистор → анод светодиода (длинная нога) → катод (короткая) → GND.

### Код: мигание внешним светодиодом

```cpp
const byte LED_PIN = 8;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(500);
  digitalWrite(LED_PIN, LOW);
  delay(500);
}
```

Ничего нового по сравнению с главой 1, кроме пина. Смысл — проверить, что схема собрана правильно.

### ШИМ: `analogWrite`

Не все пины умеют ШИМ. На Uno это **3, 5, 6, 9, 10, 11** (глава 2). `analogWrite(pin, value)` где `value` — **0–255**:

- 0 — всегда LOW
- 255 — всегда HIGH
- 128 — 50% времени HIGH, 50% LOW (частота ~490 Гц на большинстве пинов, ~980 Гц на 5 и 6)

```cpp
const byte LED_PIN = 9;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  for (int brightness = 0; brightness <= 255; brightness++) {
    analogWrite(LED_PIN, brightness);
    delay(5);
  }
  for (int brightness = 255; brightness >= 0; brightness--) {
    analogWrite(LED_PIN, brightness);
    delay(5);
  }
}
```

Светодиод плавно разгорается и гаснет. Это **не аналоговое напряжение** — это быстрое включение/выключение. Глаз усредняет.

**Ограничение**: `analogWrite` на пине, который не ШИМ (например, 4 или 7), просто даст HIGH при значении >127 и LOW при ≤127. Не ошибка компиляции — тихая ошибка поведения. Проверяй пин по таблице.

### Реле и нагрузка

Реле — электромеханический переключатель. Модуль реле обычно имеет вход управления, который принимает HIGH/LOW. **Питание катушки реле — от 5V, не от пина.** Пин управляет только оптопарой/транзистором на модуле.

```cpp
const byte RELAY_PIN = 7;

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  digitalWrite(RELAY_PIN, LOW); // большинство модулей: LOW = выключено
}

void loop() {
  digitalWrite(RELAY_PIN, HIGH);
  delay(3000);
  digitalWrite(RELAY_PIN, LOW);
  delay(3000);
}
```

**Важно**: у многих модулей логика **инвертирована** — LOW включает реле. Проверяй конкретный модуль. И **никогда не коммутируй реле 220 В, если не понимаешь, что делаешь**. Это не про Arduino, это про безопасность.

### Что может пойти не так

- **Светодиод не горит** — перепутана полярность (анод/катод). Длинная нога — анод, к пину через резистор.
- **Светодиод горит тускло** — резистор слишком большой (например, 10 кОм вместо 220 Ом).
- **Пин «умер»** — подавал ток больше 40 мА (например, светодиод без резистора). Пин может выжить, может деградировать. Не проверять.
- **`analogWrite` не плавно** — пин не ШИМ. Смотри таблицу.
- **Реле щёлкает, но нагрузка не работает** — реле коммутирует не ту линию, или модуль требует питания 5V на пин VCC (не от пина управления).
