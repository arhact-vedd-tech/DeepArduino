## Глава 8: Библиотеки

### Цель

Понять, что такое библиотека, как её установить в VS Arduino и как подключить. В конце — рабочий пример с `Servo`.

### Что такое библиотека

Библиотека — это набор готового кода, который решает конкретную задачу: управление серво, чтение датчика, вывод на дисплей. Вместо того чтобы писать с нуля тайминги ШИМ для сервопривода, ты пишешь `myservo.write(90)` — и всё работает.

Библиотека состоит из файлов `.h` (заголовки) и `.cpp` (реализация). Для использования достаточно подключить заголовок через `#include`.

### Установка библиотеки в VS Arduino

Расширение HiTECH имеет собственный менеджер библиотек, работающий через `arduino-cli` .

**Порядок:**

1. `Ctrl+Shift+P` → **VS Arduino: Library Manager** (или аналогичная команда в палитре).
2. В поиске введи название: `Servo`.
3. Найди **Servo by Michael Margolis** (это стандартная библиотека Arduino, входит в большинство установок, но лучше убедиться).
4. Установи.

**Важно**: библиотеки ставятся в глобальную папку Arduino (`Documents/Arduino/libraries` на Windows), **не в папку проекта** . Если скопировать библиотеку в папку скетча — VS Arduino её не увидит.

**Альтернатива**: если библиотеки нет в менеджере (кастомная с GitHub), скачай `.zip` и установи через `VS Arduino: Install Library from ZIP` (если команда есть) или распакуй вручную в `Documents/Arduino/libraries`. Имя папки внутри должно совпадать с именем `.h`-файла.

### Подключение: `#include`

```cpp
#include <Servo.h>
```

Угловые скобки `< >` — поиск в системных путях библиотек. Кавычки `" "` — сначала в папке скетча, потом в библиотеках .

**Классическая ошибка**: `#include <Servo>` без `.h`. Компилятор скажет `No such file or directory`. Нужен именно файл: `Servo.h` .

### Пример: Servo

Серво — мотор с обратной связью, поворачивается на заданный угол (обычно 0–180°). Управляется одним сигнальным проводом.

**Подключение:**

| Серво | Uno |
|---|---|
| Коричневый/чёрный (GND) | GND |
| Красный (VCC) | 5V |
| Оранжевый/жёлтый (сигнал) | Пин 9 |

**Важно**: серво при движении потребляет сотни мА. Питание от пина 5V Uno может проседать, если серво мощный. Для одного SG90 — обычно хватает. Для нескольких или мощных — отдельный источник 5V, GND соединить с GND платы.

**Код: базовое позиционирование**

```cpp
#include <Servo.h>

Servo myservo;

void setup() {
  myservo.attach(9);
}

void loop() {
  myservo.write(0);
  delay(1000);
  myservo.write(90);
  delay(1000);
  myservo.write(180);
  delay(1000);
}
```

`attach(9)` привязывает объект к пину 9. `write(angle)` — угол в градусах .

**Код: плавный свип**

```cpp
#include <Servo.h>

Servo myservo;

void setup() {
  myservo.attach(9);
}

void loop() {
  for (int pos = 0; pos <= 180; pos++) {
    myservo.write(pos);
    delay(15);
  }
  for (int pos = 180; pos >= 0; pos--) {
    myservo.write(pos);
    delay(15);
  }
}
```

`delay(15)` даёт серво время доехать до позиции. Без задержки цикл пролетит быстрее, чем мотор успеет отработать .

### Что может пойти не так

- **`Servo.h: No such file or directory`** — библиотека не установлена или установлена не в ту папку. Проверь Library Manager, переустанови .
- **Серво дёргается или плата перезагружается** — питание проседает. Отдельный источник питания для серво.
- **Серво не двигается** — сигнальный провод не на том пине, или `attach()` не вызван, или серво не получает питание.
- **Серво жужжит и греется** — команда на угол за пределами механического диапазона (например, 180° для серво, который физически крутится только до 160°). Не держи серво в упоре.
- **`attach()` на пине, занятом другим делом** — `Servo` использует таймер, конфликт с `analogWrite` на пинах 9 и 10. Если используешь `Servo`, ШИМ на 9/10 может работать некорректно.

### Задание

1. Подключи серво к пину 9. Загрузи свип. Убедись, что двигается.
2. Управляй серво потенциометром: `analogRead(A0)` → `map(raw, 0, 1023, 0, 180)` → `myservo.write(angle)`. Проверь плавность.
3. Подключи второй серво к пину 10. Сделай так, чтобы они двигались в противофазе: первый 0→180, второй 180→0. Используй один цикл `for` и два `write`.
